# ЛР 2. Калькулятор (JavaScript)

## Тема
Продолжение проекта калькулятора из ЛР1 с программированием кнопок на JavaScript.

## Что реализовано
1. Базовые операции: `+`, `-`, `x`, `/`, `=`.
2. Сервисные операции: `C`, `+/-`, `%`, ввод точки.
3. Дополнительные функции: `backspace (⌫)`, `sqrt (√)`, `x²`, `x!`, `000`.
4. Накопляемые операции: `M+`, `M-` с выводом текущей памяти.
5. Визуальные функции: смена фона калькулятора (`BG`), смена цвета текста результата (`TXT`), сброс темы (`R`).
6. Индивидуальная операция: `x³` (возведение в куб).

## Структура папки
1. `index.html` - разметка интерфейса калькулятора и кнопок.
2. `style.css` - стили калькулятора.
3. `script.js` - логика вычислений и обработчики событий.

## Запуск
1. Открыть `lab_2/index.html` в браузере.
2. Рекомендуемый вариант: запуск через Live Server в VS Code.
