# PSP

Работы разнесены по отдельным веткам, чтобы можно было переключаться между лабораторными как между самостоятельными состояниями проекта.

## Ветки

- `lab_1` - первая лабораторная.
- `lab_2` - вторая лабораторная.
- `Lab_3` - третья лабораторная.
- `DZ_1` - домашнее задание 1: функции НОД и RLE.
- `DZ_2` - домашнее задание 2: 3D модель Three.js.
- `lab_4` - четвертая лабораторная.
- `lab_5` - пятая лабораторная.
- `lab_6` - шестая лабораторная.

Пример переключения:

```powershell
git switch lab_4
```

После переключения в рабочей папке будут сразу видны файлы выбранной работы без дополнительной папки-прослойки.
