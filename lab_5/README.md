# ЛР 5. AJAX-запросы к API

## Что реализовано

1. Фронтенд сайта перенесен в отдельную папку `lab_5`.
2. Карточки сервисов на главной странице загружаются через `XMLHttpRequest` из API ЛР4.
3. Страница подробной карточки тоже получает данные через API по `id`.
4. Добавлен слой `modules`:
   - `ajax.js` - универсальный класс для `GET`, `POST`, `PATCH`, `DELETE`.
   - `stockUrls.js` - адреса API `http://localhost:3000/stocks`.
   - `stockMapper.js` - преобразование данных API в формат карточек сайта.
5. В сервер ЛР4 добавлены CORS-заголовки, чтобы запросы из Live Server не блокировались браузером.

## Как запускать

1. Запустить backend ЛР4:

```powershell
cd C:\Users\grigo\PSP\lab_4
npm install
npm run start
```

2. Открыть `lab_5/index.html` через Live Server.

3. Проверить в браузере:
   - на странице отображаются карточки из API;
   - при клике открывается детальная карточка;
   - во вкладке DevTools `Network` видны запросы к `http://localhost:3000/stocks`.
